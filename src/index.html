Хранение данных

На каждом компьютере выберите одну и ту же папку на сетевом диске. Записи сохраняются по очереди. При потере связи сохранение будет отменено.

Подключение другой папки не переносит текущие контакты. Чтобы перенести базу, сохраните резервную копию как contacts.sqlite в новой папке, затем подключите её на всех ПК.

Резервные копии

Копия содержит все контакты и связи. Для восстановления подключите папку с нужным файлом contacts.sqlite. Перед заменой базы закройте приложение на всех ПК.

Обновления

Проверка через GitHub Releases. Установка — только с вашим подтверждением.
